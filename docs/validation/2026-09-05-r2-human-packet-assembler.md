# R2 consolidated human packet assembler

Date: 2026-09-05

Status: structural implementation only. No real packet assembled, human
decision recorded, historical admission made, or provider run launched.

## Contract and boundaries

`scripts/evidence/assemble-human-review-packet.ts` accepts a versioned request
with an opaque source manifest, its caller-held SHA-256, and an explicit list
of included files and their SHA-256 values per dossier. It does not parse
causal content or infer source-format semantics. The preparer must verify the
list is complete and that referenced evidence is available before delivery.

Each dossier declares `ready-for-human-review` or `reconstruction-loss`.
Ready cards retain `human-evidence-card.md` or `human-review-card.md`; losses
retain `sampled-loss.md`. The output namespaces the original files by dossier,
provides a linked index, preserves losses, and creates blank response templates.
The packet manifest binds copied and generated bytes. Responses must be copied
to a separate folder before editing; modifying the packet invalidates its seal.

Assembly is review-only and non-admissible. It establishes neither semantic
completeness, reference closure, independent human confirmation, protected
selection, nor partition assignment. It cannot prove that an operator supplied
every attempted candidate. Final readiness still requires the packet-spec
inventory reconciliation, duplicate-family and corpus-balance checks, all
proof/replay limitations, and one consolidated human review.

No original source file is rewritten. Source and destination trees must be
disjoint; existing outputs, traversal, symbolic-link components, duplicate
identifiers/paths/manifests, and mismatched file bytes are rejected. Captured
bytes are used for both hashing and copying. This assumes a stable trusted
local filesystem, not protection against a concurrently malicious host.

## Usage

After the complete assembly request has been prepared and independently
reconciled against its source inventory:

```sh
source /Users/petergray/.nvm/nvm.sh
nvm use 22
node --import tsx scripts/evidence/assemble-human-review-packet.ts \
  /absolute/path/assembly-request.json /absolute/path/new-packet-directory
```

The destination parent must already exist. Do not run this on partial batches
for delivery to the user. The request interfaces are exported by the script;
the test fixture demonstrates the exact shape without exposing real answers.
