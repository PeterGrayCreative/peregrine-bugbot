subdirectory and creates one schema-valid confirmation per R1 case. No
confirmation exists yet; an empty directory is not evidence of review.

See [the review protocol](../review-protocol.md),
[`confirmation.schema.json`](../confirmation.schema.json), and the generated
[`packet-manifest.json`](../packet-manifest.json).

counted. The current machine-verifiable readiness is therefore 0/2 for every
case.
