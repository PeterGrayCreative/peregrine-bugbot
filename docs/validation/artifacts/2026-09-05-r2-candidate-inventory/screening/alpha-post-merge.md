## Uncertainties and next gate

- Discovery is biased toward issues whose title literally contains “regression,” and all API bodies are 2026 retrievals. `updatedAt`, edited comments, deleted material, and contemporaneous availability still require archival audit.
- Issue authors, maintainer comments, closing links, bisects, and later fixes are leads, not proof. Each candidate still needs authoritative repository objects, exact reviewed base/head, changed-file and test history, causal reachability from the historical diff, observable consequence, smallest repair boundary, provenance/license review, and explicit limitations.
- A fix that predates the screened report (#15760), or a fix PR already open when the report arrived (#4735), is useful for recovery but requires careful time ordering. Multiple reports/fixes that share one root must remain one family and one partition.
- The strongest immediate reconstruction leads are VS Code #99825, Next.js #1798/#8045, Sequelize #7771, webpack #11707, and RxJS #4751 because each supplies a narrow behavior, a linked repair, and an exact or near-exact introducing path. This is a prioritization judgment only, not admission.
