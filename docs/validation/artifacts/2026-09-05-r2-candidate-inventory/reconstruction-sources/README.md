Exact captured responses and canonical full-index review/repair diffs are
copied unchanged from the reconstruction scratch stores:

| Original prefix | Archive prefix from the R2 artifact root |
| --- | --- |
| `/private/tmp/peregrine-r2-bull-reconstruction/` | `reconstruction-sources/bull/` |
| `/private/tmp/peregrine-r2-alpha-reconstruction/` | `reconstruction-sources/alpha/` |

Source clones (`repos/`, `sources/`, and `next.js/`) are not copied into this
archive. They remain in the named scratch locations. The archive therefore
does not yet constitute a self-contained historical replay bundle. Admission
must authenticate and materialize the complete reviewed trees; a diff and a
source commit identifier alone do not establish future object availability.

The Bull raw store preserves its original flat layout of receipt and response
files; the other stores retain separate objects and requests directories.
Original reports remain unchanged. Independent check records narrow or correct
their claims without overwriting the original analysis. No source code was
executed, and these AI checks are not independent human admission.
